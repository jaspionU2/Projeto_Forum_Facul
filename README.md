# 🎓 Fórum Acadêmico

Plataforma de discussão e interação acadêmica focada no isolamento por campus e moderação dinâmica. Desenvolvida com backend em Laravel, persistência em PostgreSQL e interface via Blade/Vue.

## 🚀 Tecnologias Utilizadas
* *Backend:* PHP 8+ / Laravel 11
* *Banco de Dados:* PostgreSQL (deploy futuro via Supabase)
* *Frontend:* Componentes Blade e Vue.js
* *Infraestrutura:* AWS (deploy)

## 🛠️ Requisitos do Sistema
* PHP 8.2 ou superior (com extensão php-pgsql ativada)
* Composer
* PostgreSQL rodando localmente (porta 5432)
* Node.js e NPM
